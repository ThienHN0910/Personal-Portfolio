Sentinel is a comprehensive Discord community bot and live web dashboard built with TypeScript, Fastify, and Vue 3. It bridges real-time chat and voice analytics with an interactive server economy (DNE Coins), atomic Escrow wagering, ephemeral zero-trace confessions, virtual pets, and cross-platform mini-games shared seamlessly between Discord and the web.

The community engagement problem

Modern online communities exist in a state of high velocity: conversations, voice sessions, and informal social activities happen constantly across disjointed channels. Server administrators struggle to gauge authentic participation without wading through fragmented logs or falling for misleading bot demos. Furthermore, community gamification systems often compromise privacy or lack transactional rigor, leading to currency exploits and broken trust.

Sentinel approaches community operations with strict engineering honesty: the web dashboard reads directly from the authoritative bot-owned database, voice session durations distinguish finalized records from active estimates, anonymous confessions maintain a zero-trace guarantee, and mini-games share authoritative state machines between Discord buttons and web clients.

System architecture & Surface boundaries

The Discord Gateway feeds a modular Node.js service orchestrated under PM2. A Fastify HTTP/WebSocket API provides cached analytical snapshots, guild administration, and shared game coordination. MongoDB Atlas persists cumulative counters, hashed session tokens, escrow ledgers, and scheduled jobs. A Vue 3 Single Page Application on Vercel delivers responsive, real-time dashboards to public viewers and authorized administrators.

DNE Economy, Escrow betting & Zero-Death virtual pets

Beyond basic text counting, Sentinel implements a comprehensive server economy centered around DNE Coins. Members earn coins through active voice participation, message activity, daily attendance streaks (20-hour cadence with a 7-day progression ladder), and weighted gacha spins with guaranteed pity thresholds.

To allow wagering without economic race conditions, Sentinel introduces a transactional Escrow Betting System for 1v1 P2P wagers and community pool betting. Challenge stakes are deducted immediately and locked in escrow within MongoDB; once a game concludes or expires, winnings are settled atomically. Wagers cannot be duplicated or spent concurrently.

For social companionship, the Virtual Pet System adheres to an explicit Zero-Death Invariant: pets never die from neglect. Instead, a finite-state mood machine transitions between Happy, Hungry, and Sad based on daily feeding (/pet feed) and play actions (/pet play), encouraging positive community interactions without punishment.

Zero-Trace anonymity & Cross-Surface state machines

For sensitive community sharing, Sentinel's confession pipeline enforces Zero-Trace Anonymity: incoming confessions submitted via slash command modals or direct messages are sanitized and relayed directly to the configured guild confession channel. The system deliberately discards all sender identifiers: no userId, IP hash, or audit record is ever written to disk or database.

Interactive games—such as Tic-tac-toe, Rock-paper-scissors, Wordchain (nối từ), and Bầu cua—span both Discord buttons and web browser tabs. Each session is backed by a server-side finite-state machine with versioned optimistic concurrency checks (version: state.version). Two players can engage with one in Discord and one on the web, with stale or conflicting clicks rejected cleanly at the database boundary.

Operations, reliability & Scheduled digests

Sentinel operates as a long-running service on a production VPS managed by PM2, complemented by automated telemetry endpoints (/api/health) reporting memory usage and gateway latency. A resilient cron worker coordinates weekly community digest reports delivered at 09:00 Monday GMT+7 to designated guild announcement channels, with exponential retry policies preventing duplicate dispatches.
