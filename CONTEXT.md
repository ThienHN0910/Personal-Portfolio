# Personal Portfolio & Architecture Platform

Canonical domain terminology and architectural concepts for Hồ Ngọc Thiện's personal portfolio and technical publication platform.

## Language

### Core Entities

**Case Study**:
An in-depth technical analysis of a production platform, software architecture, or distributed tool built by the engineer, highlighting problem context, design tradeoffs, implementation, and measurable results.
_Avoid_: Project, Work item, Repo, Assignment

**Article**:
A long-form technical publication covering software design patterns, framework internals (Vue 3 / TypeScript), web performance engineering, or architecture philosophies.
_Avoid_: Blog post, Post, Entry, Article note, Diary

**Publication**:
The curated collective archive or category stream of technical articles and architectural notes.
_Avoid_: Blog, Feed, Newsfeed

**Skill Matrix**:
A categorized inventory of technical competencies, framework proficiencies, and engineering capabilities.
_Avoid_: Tech stack list, Tags, Keywords

**Work Chronology**:
A verified timeline of professional engineering roles, responsibilities, and achievements.
_Avoid_: Job history, Work experience list

### Content & Media

**Rich Content**:
HTML markup generated by CKEditor containing formatted text, code blocks, tables, pull-quotes, and embedded media, sanitized at client runtime before DOM injection.
_Avoid_: Raw HTML, WYSIWYG dump

**System Spec Rail**:
The sticky technical sidebar in a Case Study displaying metadata metrics, active deployment status, domain classification, and repository links.
_Avoid_: Info sidebar, Details box

**Snapshot Prerender**:
A build-time process that generates pre-rendered HTML files with full OpenGraph/Twitter meta tags for crawlers while preserving SPA client interactivity.
_Avoid_: SSR, Server rendering, Dynamic crawler injection

**Optimized Asset Delivery**:
Media stored and served via Cloudinary global CDN with dynamic format and compression negotiation (`f_auto,q_auto`).
_Avoid_: Local uploads, Static server files

### Security & Inbound Communication

**Bearer Session**:
Stateless JWT authentication token stored in client `localStorage` and transmitted via HTTP `Authorization: Bearer <token>` header across independent Vercel origins.
_Avoid_: Cookie session, Stateful server session

**Multi-Channel Inbound Notification**:
Immediate dual dispatch of contact form inquiries via transactional Nodemailer email and Telegram Bot Webhook.
_Avoid_: Email-only alert, Polling inbox

### AI & Design System Synthesis

**Decoupled Case Study Architecture**:
Completely autonomous Case Studies containing self-contained architectural dossiers without relying on external Article foreign keys (`relatedBlogId`).
_Avoid_: Linked blog post, Project companion post

**Design-System-Constrained AI Synthesis**:
AI content generation strictly constrained to standard semantic HTML tags and predefined design system CSS classes (`.article-*`, `.project-*`, `.editorial-*`), allowing inline styles *exclusively* for creative CSS Grid layout orchestration.
_Avoid_: Unconstrained HTML dump, Ad-hoc inline colors/fonts
