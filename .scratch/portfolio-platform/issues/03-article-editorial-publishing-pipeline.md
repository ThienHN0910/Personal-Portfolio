# 03: Article & Editorial Rich Content Publishing Pipeline

**What to build:** An authoritative technical publication system for long-form engineering articles. Features client runtime HTML sanitization with strict DOMPurify protection, automatic normalization of video media from oEmbed to responsive iframes, luxury magazine pull-quotes, dark syntax-highlighted code blocks, responsive data tables, and a sticky reading progress bar.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Visitors can read long-form technical Articles with high-contrast typography, styled callouts, and obsidian code blocks
- [ ] Client runtime sanitization strictly strips malicious scripts, dangerous attributes, and untrusted iframe sources
- [ ] YouTube and Vimeo oEmbed media links are automatically converted into sandboxed, responsive 16:9 iframe embeds
- [ ] Reading progress bar tracks scroll position accurately across desktop and mobile screens
- [ ] Estimated reading time and formatted publication timestamps are displayed on both card previews and detail views
